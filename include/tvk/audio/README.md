# `tvk/audio` — Audio Subsystem

Planned headers for game audio and procedural sound synthesis (see [`ROADMAP.md`](../../../ROADMAP.md) — Phase 7):

- `AudioEngine.h` — Cross-platform non-blocking audio mixer and spatial 3D attenuation.
- `Sound.h` — WAV/PCM sample buffer and procedural retro synth generator (square, saw, triangle, noise envelopes for terminal games).
